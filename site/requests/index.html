If Ben sent you this link, you're in the right place. This page isn't linked from anywhere — it's for you.

How it works

  • 01 Open requests.bennelson.dev.
  • 02 Enter your email — a one-time code lands in your inbox. That's the door check: only invited addresses get a code. You'll repeat this about once a month per device.
  • 03 Hit the log-in button — it uses an account you already have. No new password, nothing to remember.
  • 04 Search for the thing. Hit Request. It shows up on its own — usually fast, occasionally "the basement is thinking about it."

Make it feel like an app

Once you're signed in, add it to your home screen and it behaves like a native app:

  • iphone Share button → Add to Home Screen.
  • android Browser menu → Add to Home screen (or Install app).

Requests are reviewed by a very serious automated pipeline and one guy in a basement.
