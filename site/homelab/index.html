the homelab

Everything on the dashboard runs on hardware in my basement. This is the short tour.

the basement

Self-hosting is the whole personality of this setup: if I use it every day, I want it running on something I can physically reach. The result is a fleet of machines with one production server at the center: a mid-tower in the basement running the media server, network storage, home automation, and every app on the dashboard.

A note on names: every machine below is renamed for publication. The real hostnames stay home; the kitchen appliances are stand-ins. the real names are frogs. wait. forget i said that.

the hardware

unitrolenotes
crockpot 🍲 production. 6-core, 16GB, Linux Runs everything: the media server, ~20 containers, network shares, and the home-automation brain.
the array 7.5TB usable RAID5 Three drives, survives losing any one of them. Health-checked nightly; the irreplaceable stuff also leaves the house every night, encrypted.
minifridge 🧊 public VPS The only machine that lives on the open internet, deliberately outside the home network with no way back in.
airfryer / toaster / microwave dev machines Where things get built before they're allowed in the basement. the airfryer is fast. suspiciously fast.

mission control

All of it is observable from home-hq, the self-hosted dashboard that started this whole thing. The real one never leaves the house, but there's a full simulation with canned data you can click around.

House rules: deny by default, pin versions, and write down anything weird.
